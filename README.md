# Nederlands Leren App 🇳🇱🇺🇦

Інтерактивний веб-додаток для вивчення нідерландської мови, розроблений для українців.

## 🚀 Можливості

- **Артиклі `de` / `het`**: Практика визначення артиклів для нідерландських іменників із візуальним фідбеком.
- **Питальні слова (`Pytwoorde`)**: Вправи для засвоєння слів-запитань (*wat*, *waarom*, *wanneer*, *wie*, *waar*, *hoe*, *welke*, *hoeveel* тощо).
- **Підсумки після кожного кругу**: Детальна статистика результатів (кількість правильних відповідей та відсоток успішності) після кожної серії з 10 питань.
- **Захист від випадкових кліків**: Плавна анімація з затримкою для перегляду правильної відповіді без перескакування слів.

## 🛠️ Технології

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **Tailwind CSS** (через CDN)
- Single-page application (SPA), що працює повністю в браузері без додаткових залежностей чи серверної частини.

## 📦 Як запустити локально

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/your-username/nederlands-leren.git
   ```
2. Відкрийте файл `index.html` у будь-якому сучасному браузері.

## 🌐 Публікація через GitHub Pages

Щоб зробити додаток доступним онлайн через GitHub Pages:

1. Перейдіть у налаштування вашого репозиторію на GitHub (**Settings**).
2. У лівому меню оберіть розділ **Pages**.
3. У блоці **Build and deployment** під пунктом **Source** оберіть `Deploy from a branch`.
4. У пункті **Branch** виберіть гілку `main` (або `master`) та папку `/ (root)`.
5. Натисніть **Save**.
6. За декілька хвилин ваш сайт буде доступний за адресою: `https://<ваш-username>.github.io/<назва-репозиторію>/`.
